# 黑貓翻翻樂｜世界黑貓日

拼圖喵為 10.27 世界黑貓日製作的翻牌小遊戲。12 張牌、6 隻黑貓，翻開兩張找配對，計時看看多久能找齊。

## 檔案結構

```
index.html          遊戲頁面
images/logo.png     拼圖喵 LOGO
images/cats/        六隻黑貓的照片
```

## 用 GitHub Pages 上線

1. 在 GitHub 建立一個新的 repository（例如 `black-cat-game`），設為 Public。
2. 進入 repository，點「Add file」→「Upload files」，把這個資料夾裡的所有檔案和 `images` 資料夾一起拖進去，按「Commit changes」。
3. 到「Settings」→「Pages」，在「Build and deployment」的 Source 選「Deploy from a branch」，Branch 選 `main`、資料夾選 `/ (root)`，按「Save」。
4. 等一兩分鐘，網址會出現在同一頁上方，格式是 `https://你的帳號.github.io/repository名稱/`。

## 更換照片

把新照片用相同檔名放進 `images/cats/` 覆蓋即可。照片建議裁成正方形。
